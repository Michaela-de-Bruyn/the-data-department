## 💻 About

The Data Department is an interactive portfolio showcasing data engineering, analytics and data projects.

The site uses a SQL-inspired interface with a feminine dark theme, terminal-style elements and project cards representing real data engineering work.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- JetBrains Mono
- Font Awesome
- Git
- GitHub
- Vercel
